# Setup Guide

## Overview

This project demonstrates a highly available web application using AWS EC2, NGINX, an Application Load Balancer (ALB), and a Target Group.

## Steps

1. Launched two EC2 instances.
2. Installed and configured NGINX.
3. Created a custom HTML website.
4. Created a Target Group with health checks.
5. Created an Application Load Balancer.
6. Registered both EC2 instances.
7. Verified website accessibility through the ALB.

## Result

The website remains available even if one server becomes unavailable.
