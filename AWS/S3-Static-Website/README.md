# AWS S3 Static Website

## Overview
This project demonstrates hosting a static website on AWS S3.

## Files
- `index.html` – Main webpage
- `screenshots/` – Screenshots:
  - `screenshot index.html.png`
  - `screenshot website-live.png`
  - `screenshot bucket-settings.png`

## Deployment Steps
1. Create an S3 bucket.
2. Upload `index.html` and assets.
3. Enable static website hosting in bucket properties.
4. Configure public access permissions.
5. Access the website using the S3 endpoint.
